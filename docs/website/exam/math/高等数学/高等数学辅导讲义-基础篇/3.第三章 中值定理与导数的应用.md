## 第一节 中值定理与洛必达法则

### 一、中值定理

<span :class="[$style.title,$style.bold]">引理（费马定理）</span> 设函数 $f(x)$ 可导，且在 $x=x_0$ 处取极值，则 $f'(x_0)=0$，反之不对。

:::tip 证明
不妨设 $x=x_0$ 为极大值点，则存在 $\delta\gt0$，
:::
